# 🛒 Big Mart Sales Prediction

## 📌 Project Overview

Big Mart Sales Prediction is a Machine Learning project that predicts the sales of products in retail outlets based on various product and store-related attributes. The project uses historical sales data to identify patterns and build a predictive model that estimates product sales.

By applying data preprocessing, Exploratory Data Analysis (EDA), feature engineering, and Machine Learning techniques, this project aims to support better retail decision-making, sales forecasting, and inventory planning.

## 🎯 Objectives

- Analyze historical retail sales data.
- Perform data cleaning and preprocessing.
- Explore sales trends and patterns through visualizations.
- Identify important features affecting product sales.
- Train a Machine Learning model for sales prediction.
- Evaluate the model's predictive performance.

## 📊 Dataset

The dataset contains information about products and retail outlets.

### Key Features

- **Item Identifier:** Unique ID of the product.
- **Item Weight:** Weight of the product.
- **Item Fat Content:** Fat-content category of the product.
- **Item Visibility:** Visibility of the product in the store.
- **Item Type:** Category of the product.
- **Item MRP:** Maximum Retail Price of the product.
- **Outlet Identifier:** Unique ID of the outlet.
- **Outlet Size:** Size of the retail outlet.
- **Outlet Location Type:** Location category of the outlet.
- **Outlet Type:** Type of retail outlet.
- **Item Outlet Sales:** Target variable used for sales prediction.

*Note: The features may vary depending on the dataset used in the project.*

## 🤖 Machine Learning Algorithm

**Random Forest Regression**

Random Forest Regression is an ensemble Machine Learning algorithm that combines multiple decision trees to generate predictions. It is used in this project to estimate product sales by learning patterns from the dataset.
